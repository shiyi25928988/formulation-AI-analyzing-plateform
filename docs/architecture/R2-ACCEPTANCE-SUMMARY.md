## 4. R2 验证证据要点（对外可引用口径）

1. **主动学习有效性**（B02）：12 种子合成回放，对 random 基线降 **84.6%**（bootstrap CI [44.6%, 89.4%]）、对 historical 降 **88.9%**（CI [65.4%, 94.5%]），通过门禁；对 greedy 未过（**如实记录，未修饰**）
2. **静默失败防护**（B06）：八类故障注入**拦截率 8/8=100%**，强口径（每条金丝雀均拦截）；断言层与偏差层互补性验证成立
3. **端到端闭环**（B03）：§18.2 十步全落点，两轮闭环推荐变化、审计按推荐 id 反查完整
4. **契约完备性**（B04）：九服务 OpenAPI + 19 事件，发现并解决 intervals 必返 vs severe 拒答的契约自冲突（移出 required + 语义条件校验强制）
5. **训练-服务一致性**（B07）：特征指纹内容寻址，训练/服务/金丝雀共用同一工厂实例
6. **生命周期可审计**（B09）：门禁失败=不入册 + `ModelGateFailed` 留痕；G0–G5 短路求值 SKIPPED 可反查；模型卡 `auto_fill_ratio` **实测 0.8947**（DoD 1 ≥0.80）；白名单与 DDL 由**镜像断言机械绑定**（DoD 2）；金丝雀作为 canary 门禁单一来源引用（DoD 3）
